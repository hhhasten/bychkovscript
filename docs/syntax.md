# Синтаксис БичковСкрипту

Синтаксис BychkovScript є по суті солянкою з TypeScript та Python, з деякими елементами Rust. В цілому мало чим відрізняється від сучасних мов
___
## Змінні та константи
Змінні оголошуються за таким принципом:
```aiignore
модифікатор ідентифікаторЗмінної: тип = значення;
```
- `модифікатор` - `let` - для змінних, `const` - для констант
- `ідентифікаторЗмінної` - назва змінної, зазвичай у форматі camelCase
- `тип` - тип змінної, детальніше в [типи даних](../docs/types.md)
- `значення` - і так ясно
- `;` - крапка з комою опціональна, можна не ставити

Приклади:
```aiignore
let a: int = 5;
const PI: float = 3.1415;
let b: str = "Hello world!";
let arr: list|int = [1, 4, 6, 5, 4];
```

Також перед першим релізом я реалізував коротку форма запису через `:=`, надихнувшись GoLang. Принцип оголошення:
```aiignore
let a := 5 # Автоматично отримує int
let name := "Льоха" # Автоматично отримує str
```

Звісно, також існує оголошення без ініціалізації:
```aiignore
let a: int
const b: str

a = 129
```

```aiignore

```

## Умовні конструкції
Як і у інших повноцінних мовах присутні умовні оператори `if`/`else` та цикли `while`, `for`

Структура `if` та `else` майже нічим не відрізняється від того до чого ми звикли:
```aiignore
if (5 > 10) {
    ###
} else if (isValid === TRUE) {
    ###
} else {
    ###
}
```
Але от самі умови зазнали змін
- Ті самі `===` та `!==` з JavaScript яких багато хто ненавидить
- Замість унарного оператора `!` ми використовуємо тильду `~`
````aiignore
if (~(a >= 5)) {
    ###
}
````
- На момент релізу 1.0.0 нажаль **відсутній** спрощений вигляд для булевих значень:
```aiignore
### НЕМАЄ ТАКОГО ПОНЯТТЯ:   if (isNice)
### ТРЕБА ПИСАТИ ПОВНЕ      if (isNice === TRUE)
```
- Для складних умов використовуємо ключові слова `or` та `and`
```aiignore
if (a > b and b <= c) {
    ###
}
if (isDay === TRUE or isEvening === TRUE) {
    ###
}
```

Цикл `while` має вже звичну для С-подібних мов структуру:
```aiignore
while (умова) {
    # тіло циклу
}
```
А от цикл `for` реалізований як в тому самому Rust, через проміжки:
```aiignore
for i in 0..10 {
    println!(i)
}

### --- Можна використовувати змінні

let start := 100
let end := 200

for i in start..end {
    # логіка якась
}
```

## Функції та методи

Функції в БичковСкрипті діляться на **нативні** та **ненативні**.

Нативні функції позначені знаком `!`, вони інтерпретуються напряму у C#.
Нативні функції зазвичай виконують роботу низького рівня, як те ж саме виведення у консоль.

Список Нативних функцій на момент релізу 1.0.0:

- `print!()` - Виведення рядка у консоль
- `println!()` - Виведення рядка з переходом на слідуючий рядок
- `input!()` - Повертає дані у консоль у форматі рядка str
- `cls!()` - Чистить консоль
- `wait!()` - Зупиняє поток на вказану кількість мілісекунд
- `toInt!()` - Конвертація у ціле число
- `toFloat!()` - Конвертація у число з плаваючою точкою
- `len!()` - Повертає довжину списка
- `push!()` - Додає елемент у список
- `pop!()` - Дістає останній елемент зі списка
- `removeAt!()` - Видаляє елемент на вказаному індексі
- `contains!()` - Перевірка на присутність значення у списку
- `randInt!()` - Повертає рандомне число у вказаному діапазоні
- `randSingle!()` - Повертає рандомне дробне число (float) від 0.00 до 1.00

Ненативними є функції оголошені власне мовою BychkovScript. Це усі функції оголошені розробником або функції з бібліотек

Оголошується типова функція так:

```aiignore
fn add(arg1: int, arg2: int) -> int {
    let result := arg1 + arg2
    return result
}
```
Тут ми бачимо пайтонівський вид: спочатку ключове слово, потім назва, аргументи в дужках та стрілочка яка вказує тип повертаємого значення.

Для функцій які повертають `void` можна не писати стрілочку та `return`:
```aiignore
fn sayHello(person1: str, person2: str) {
    println!(person1 + ": Hello, dear " + person2)
}

sayHello("Бичков", "Нетаньяху")

### output: Бичков: Hello, dear Нетаньяху
```

**Методи** в BychkovScript не мають ніякого відношення до ООП, методи це всього лиш прикольна фіча.

Метод - це тут бляха просто функція яка викликається через крапку. Змінна до якої ми викликали метод буде першим аргументом.

Оголошення методів буквально відрізняється одним словом: замість `fn` використаємо `mtd`

```aiignore
mtd sayHello(person1: str, person2: str) {
    println!(person1 + ": Hello, dear " + person2)
}

"Бичков".sayHello("Нетаньяху")

### output: Бичков: Hello, dear Нетаньяху
```

Також методами є нативні функції для роботи зі списками:

`len!()`, `push!()`, `pop!()`, `removeAt!()`, `contains!()`

```aiignore
let arr: list|int = [1, 4, 5, 6];

println!(arr.len!())

### output: 4
```
