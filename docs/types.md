# Типи у БичковСкрипті
Більшість типів у цій мові є примітивними, оскільки на момент релізу 1.0.0 у БичковСкрипті відсутнє ООП та структури.

Тому ось список доступних типів:

- `int` - 1, 15, 121, 3, 5
- `float` - 1.00, 3.1415, 1298.90001
- `str` - "Israel", "KNU", "пріколи клеш рояль"
- `boolean` - TRUE/FALSE (капсом)

Також присутні дві колекції:

- Список `list|тип`:
  - є типізованим, зберігає значення одного типу, вказаного під час ініціалізації.
  - ```aiignore
    let animals: list|str = ["cat", "dog", "cow"]

    let numbers: list|int = [1, 3, 6, 8]
    ```
- Смітник `trashcan`
  - є динамічною колекцією, по суті ліст з пайтону. Так він порушує строгу типізацію БичковСкрипту, але на те він і смітник лол. Мова взагалі задумувалася як рейджбайт
  - ```aiignore
    let someShit: trashcan = [1, "chicken", TRUE, 67.228]
    ```
    
При неявній ініціалізації через оператор `:=` колекції автоматично отримують тип `trashcan`.
```aiignore
let arr := [1, 5, 6, 4] # це буде смітник
```

Багатовимірні масиви все ще знаходяться на етапі розвитку, тому працюють дуже криво, але на данний момент більш-менш придатним для користування можна використовувати лише список із смітників:

```aiignore
let matrix: list|trashcan = [[1, 41],[1, 8]]

println!(matrix[1][1])

### output: 8
```
